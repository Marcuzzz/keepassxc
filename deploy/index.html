KeePassXC with KeePass Server

Personal fork of KeePassXC that syncs databases with a self-hosted KeePass Server. Not an official KeePassXC release.

Linux (AppImage) macOS (Apple Silicon) macOS (Intel)
All releases

Linux

x86_64 AppImage, built on Ubuntu 24.04 (needs Ubuntu 24.04 or newer). Make it executable and run it:

chmod +x KeePassXC-*.AppImage
./KeePassXC-*.AppImage

macOS

Apple Silicon needs macOS 14 or newer, Intel needs macOS 15 or newer. Open the DMG and drag KeePassXC to Applications. This replaces an installed official KeePassXC.

The app is not notarized, so macOS blocks it on first launch. Allow it once with:

xattr -dr com.apple.quarantine /Applications/KeePassXC.app

or right-click the app and choose Open. Touch ID quick unlock works, but because the app is not signed with an Apple team ID, its unlock key is kept in memory instead of the Keychain (as on Linux).

Connecting to your server

Create a new database and choose KeePass Server as its location (Test connection checks the URL and login), or open an existing database from the server. The database then syncs on unlock and save, can work offline, and keeps conflict copies when changes can't be merged.

Updates

This build has update checks turned off, since they would point to official KeePassXC. New releases are published to the Releases page, and the buttons above always point to the newest one.
